الجواب الصادق من جزأين. ChatGPT في المتصفح أو على الهاتف لا يستطيع تعديل ملفات الفيديو الموجودة على جهازك. يستطيع كتابة نص وعناوين ظاهرة وقائمة لقطات. أما تطبيق ChatGPT لسطح المكتب في وضع Codex، وأداة Codex في سطر الأوامر، فيستطيعان: يعملان داخل مجلد تختاره ويشغّلان برامج مثل ffmpeg. هذه الصفحة هي جزء ChatGPT من [الدليل الكامل](/ar/guides/edit-video-with-ai-agents/).

تحتاج خطة ChatGPT تتضمن Codex.

## ما تستطيعه كل خيار

| الخيار | يقص مقاطعك المحلية؟ |
|---|---|
| ChatGPT في المتصفح أو تطبيق الهاتف | لا. للتخطيط والكتابة فقط |
| تطبيق ChatGPT لسطح المكتب، وضع Chat أو Work | فقط إذا فعّلت العمل المحلي للمجلد. وضع Work في المتصفح يعمل في بيئة سحابية |
| تطبيق ChatGPT لسطح المكتب، وضع Codex | نعم. يفتح مجلدًا ويشغّل أوامر |
| Codex CLI في الطرفية | نعم |

"العمل المحلي" يعتمد على إعدادات حسابك ومساحة عملك، فقد لا تراه. وضع Codex هو الطريق المضمون.

## 1. ثبّت تطبيق سطح المكتب

نزّل ChatGPT لـ macOS أو Windows أو Linux من OpenAI، وافتحه وسجّل الدخول. في قائمة المنتجات اختر **Codex**. ثم افتح مجلد مقاطعك كمشروع.

إذا كنت تحب الطرفية، فنسخة سطر الأوامر تُثبّت بسطر واحد:

```bash
npm install -g @openai/codex
```

أو `brew install --cask codex` على Mac. شغّل `codex` واختر **Sign in with ChatGPT**.

## 2. ثبّت ffmpeg

```bash
brew install ffmpeg
```

على Windows: `winget install Gyan.FFmpeg`. أو اطلب من Codex: "ثبّت ffmpeg لي". يطلب موافقتك قبل التشغيل.

## 3. أضف المهارات

يقرأ Codex المهارات من `.agents/skills` في مجلدك أو من `~/.agents/skills` في مجلد المنزل. ثبّت مهارتي الفيديو من [solo-factory](https://github.com/fortunto2/solo-factory):

```bash
npx skills add fortunto2/solo-factory --skill solo-transcribe --skill solo-video-edit --global
```

يحتاج هذا إلى [Node.js](https://nodejs.org). اختر Codex عندما يسألك. طريقة أخرى: اكتب في Codex الأمر `$skill-installer` واطلب منه تثبيت هاتين المهارتين من مستودع GitHub ذاك. أعد تشغيل Codex إذا لم تظهرا. لاستدعاء مهارة في رسالة، اكتب `$` ثم اسمها. لا تنسخ ملفات المهارات يدويًا.

## 4. اطلب الفيلم

> في المجلد 40 مقطعًا من يوم واحد. استخدم $solo-transcribe على كلها، واقرأ النص واقترح قصة في خمسة أسطر. انتظر ردي قبل القص.

ثم:

> اقصّ تريلر مدته 3 دقائق في هذه القصة، مع music.mp3 تحته، والقصّات على الإيقاع. أرني السكربت ولوحة مصغرات قبل الإخراج.

يفرّغ Codex الكلام، ويجد الإيقاع، ويكتب القص كسكربت، ويخرج بـ ffmpeg ويتحقق من النتيجة. توقع ثلاث جولات. القص الأول نادرًا ما يكون الذي تحتفظ به.

## أين يضعف ChatGPT

- بلا تطبيق سطح المكتب أو Codex، لا يصل إلى مقاطعك. لا تلصق فيديو بحجم 2 GB في محادثة وتتوقع قصًا.
- التفريغ على Windows وLinux يعمل على المعالج (CPU) وأبطأ منه على Mac بمعالج Apple Silicon.
- راجع ما يريد Codex تشغيله قبل أن توافق. هذه شبكة أمانك.

إذا كنت تدفع لـ Claude أصلًا، فإن [Claude Code](/ar/guides/edit-video-with-claude-code/) يؤدي العمل نفسه. وكلاهما يقرأ المهارات نفسها.
