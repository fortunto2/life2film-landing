Честный ответ состоит из двух частей. ChatGPT в браузере или на телефоне не может монтировать видеофайлы, которые лежат на вашем компьютере. Он может написать сценарий, субтитры и список кадров. Приложение ChatGPT для компьютера в режиме Codex и консольный Codex могут: они работают в выбранной вами папке и запускают программы вроде ffmpeg. Эта страница описывает часть про ChatGPT из [полного руководства](/ru/guides/edit-video-with-ai-agents/).

Нужен тариф ChatGPT, в который входит Codex.

## Что умеет каждый вариант

| Вариант | Монтирует ваши локальные клипы? |
|---|---|
| ChatGPT в браузере или приложение на телефоне | Нет. Только планирование и текст |
| Приложение ChatGPT для компьютера, режим Chat или Work | Только если включить локальную работу для папки. Work в браузере идёт в облачной среде |
| Приложение ChatGPT для компьютера, режим Codex | Да. Открывает папку, запускает команды |
| Codex CLI в терминале | Да |

«Работать локально» зависит от настроек вашего аккаунта и рабочего пространства, поэтому у вас этого пункта может не быть. Режим Codex надёжнее.

## 1. Установите приложение для компьютера

Скачайте ChatGPT для macOS, Windows или Linux на сайте OpenAI, откройте и войдите. В переключателе продуктов выберите **Codex**. Затем откройте папку с клипами как проект.

Если вам привычен терминал, консольная версия ставится одной строкой:

```bash
npm install -g @openai/codex
```

или `brew install --cask codex` на Mac. Запустите `codex` и выберите **Sign in with ChatGPT**.

## 2. Установите ffmpeg

```bash
brew install ffmpeg
```

На Windows: `winget install Gyan.FFmpeg`. Или попросите Codex: «Установи мне ffmpeg». Перед запуском он спросит подтверждения.

## 3. Добавьте навыки

Codex читает навыки из `.agents/skills` в вашей папке или из `~/.agents/skills` в домашней папке. Установите два навыка для видео из [solo-factory](https://github.com/fortunto2/solo-factory):

```bash
npx skills add fortunto2/solo-factory --skill solo-transcribe --skill solo-video-edit --global
```

Нужен [Node.js](https://nodejs.org). Когда спросит, выберите Codex. Другой способ: в Codex введите `$skill-installer` и попросите установить эти два навыка из того репозитория на GitHub. Если навыки не появились, перезапустите Codex. В сообщении навык вызывается так: введите `$` и его имя. Файлы навыков вручную не копируйте.

## 4. Попросите фильм

> В папке 40 клипов за один день. Используй $solo-transcribe на всех, прочитай расшифровку и предложи историю в пяти строках. Дождись моего ответа, прежде чем резать.

Затем:

> Смонтируй трейлер на 3 минуты в этой истории, подложи music.mp3, режь по биту. Перед рендером покажи сценарий и контактный лист.

Codex расшифрует речь, найдёт бит, запишет монтаж как сценарий, отрендерит через ffmpeg и проверит результат. Готовьтесь к трём кругам. Первый вариант редко оказывается тем, который вы оставите.

## Где ChatGPT слабее

- Без приложения для компьютера или Codex у него нет доступа к вашим клипам. Не вставляйте в чат видео на 2 ГБ в надежде на готовый монтаж.
- Расшифровка на Windows и Linux идёт на процессоре и медленнее, чем на Mac с Apple Silicon.
- Проверяйте, что Codex хочет запустить, прежде чем подтверждать. Это ваша страховка.

Если вы уже платите за Claude, [Claude Code](/ru/guides/edit-video-with-claude-code/) делает ту же работу. Оба читают одни и те же навыки.
