Claude Code это ассистент от Anthropic, который работает в папке на вашем компьютере. Он читает файлы, запускает программы вроде ffmpeg и пишет скрипты. Для монтажа видео нужно именно это. Эта страница описывает часть про Claude Code из [полного руководства](/ru/guides/edit-video-with-ai-agents/).

Нужен платный тариф Claude или аккаунт Anthropic API. Claude Code работает на macOS 13 и новее, Windows 10 и новее и Linux, от 4 ГБ оперативной памяти.

## 1. Откройте терминал

- **Mac:** нажмите Cmd+Пробел, введите «Terminal», нажмите Enter.
- **Windows:** нажмите клавишу Windows, введите «PowerShell», нажмите Enter.

У Anthropic есть [руководство по терминалу](https://code.claude.com/docs/en/terminal-guide) для новичков. Не хотите терминал? Есть [приложение Claude для компьютера](https://code.claude.com/docs/en/desktop-quickstart.md) с Claude Code внутри. Шаги с навыками ниже подходят и туда.

## 2. Установите Claude Code

Mac, Linux или WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Или через менеджер пакетов: `brew install --cask claude-code` на Mac, `winget install Anthropic.ClaudeCode` на Windows.

Пока установщик качает файлы, он ничего не печатает. Когда он остановится, откройте новое окно терминала и запустите:

```bash
claude --version
```

Номер версии значит, что всё получилось.

## 3. Установите ffmpeg и два навыка

```bash
brew install ffmpeg
```

На Windows: `winget install Gyan.FFmpeg`. Теперь навыки из [solo-factory](https://github.com/fortunto2/solo-factory):

```bash
npx skills add fortunto2/solo-factory --skill solo-transcribe --skill solo-video-edit --global
```

Нужен [Node.js](https://nodejs.org). Когда спросит, куда ставить, выберите Claude Code. Если не хотите Node, запустите `claude` и скажите: «Установи навыки solo-transcribe и solo-video-edit из github.com/fortunto2/solo-factory». Файлы навыков вручную не копируйте. Копия перестаёт получать исправления.

## 4. Запустите в папке с клипами

```bash
cd ~/Movies/lisbon-day1
claude
```

В первый раз он попросит войти в аккаунт. Дальше он спрашивает разрешения перед каждым запуском. Читайте, что он хочет выполнить. Подтверждайте то, что выглядит правильно.

## 5. Попросите фильм

> В папке 40 клипов за один день. Расшифруй их все навыком транскрипции, потом прочитай расшифровку и предложи историю в пяти строках. Дождись моего ответа, прежде чем резать.

Ответьте, что выбрали, затем:

> Смонтируй трейлер на 3 минуты в этой истории. Возьми ~/Music/score.mp3 и режь по биту. Перед рендером покажи сценарий и контактный лист кадров.

Claude Code сделает следующее:

1. запустит расшифровку, получится один текстовый файл на весь день;
2. найдёт бит вашего трека;
3. запишет монтаж как небольшой файл-сценарий;
4. отрендерит mp4 через ffmpeg и проверит, что длина и звук совпадают.

Claude Code может работать и внутри приложения Life2Film Studio на Mac: читает таймлайн, смотрит кадры и предлагает правки, которые вы принимаете в окне. Подключение одной командой, см. [Connect an agent](/studio/agent/).

## Если что-то пошло не так

- **`claude: command not found`.** Закройте терминал и откройте новый. Если не помогло, запустите `claude doctor` или посмотрите [решение проблем установки](https://code.claude.com/docs/en/troubleshoot-install.md) от Anthropic.
- **В расшифровке странные имена.** Дайте список слов: «Анна это моя сестра, кафе называется Oficina». Он исправит текст один раз, до того как его возьмут субтитры.
- **В клипе нет речи.** Толпа и музыка могут дать выдуманные фразы. Скажите: «Считай, что в клипе 17 нет речи».
- **Монтаж получился плоским.** Скажите, что не так, простыми словами. «Слишком много общих планов подряд.» «Начни с лучшего момента.»
